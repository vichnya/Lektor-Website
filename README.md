# Lektor Website

Учебный проект на Python с использованием Lektor — статического генератора сайтов и CMS.

## Цель

На практике изучить разработку и структуру проекта на Lektor, работу с моделями данных, шаблонами, контентом и статическими ресурсами.

## Что реализовано

* структура сайта на Lektor;
* собственные модели данных;
* шаблоны на Jinja2;
* разделы с информацией о проектах;
* категории проектов;
* блог с публикациями;
* статические ресурсы CSS;
* подключение и использование дополнительного Lektor-плагина.

## Структура проекта

```text
my_lektor/
├── assets/
│   └── static/
├── content/
│   ├── about/
│   ├── blog/
│   ├── project-categories/
│   └── projects/
├── models/
├── packages/
│   └── lektor-webdav/
├── templates/
├── lektorpage.lektorproject
└── README.md
```

### Основные каталоги

* `content/` — содержимое страниц, блога и проектов;
* `models/` — модели и структура данных Lektor;
* `templates/` — HTML-шаблоны на Jinja2;
* `assets/` — статические ресурсы сайта;
* `packages/` — дополнительные плагины Lektor;
* `lektorpage.lektorproject` — конфигурация проекта.

## Lektor WebDAV

В проект подключён дополнительный плагин `lektor-webdav` для работы с WebDAV.

Плагин является сторонним компонентом и используется в проекте для расширения возможностей Lektor.

## Технологии

* Python
* Lektor
* Jinja2
* HTML
* CSS
* WebDAV
* Git

## Запуск

Установить Lektor:

```bash
pip install lektor
```

Запустить локальный сервер из корня проекта:

```bash
lektor server
```

После запуска сайт будет доступен по адресу:

```text
http://localhost:5000
```

## Результат

В рамках проекта создан структурированный сайт на Lektor с собственными моделями данных, шаблонами, разделами контента, блогом и каталогом проектов.
